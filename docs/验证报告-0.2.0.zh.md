### 3. 新增「远程主机」

- 设置 → 连接 → 远程主机（`RemoteHostActivity`，独立 WebView）。
- 支持地址 + 可选 token、连通性测试（HTTP 状态码分级提示）、地址记忆。
- 与本地引擎完全隔离：不启动、不接管、不影响本地引擎生命周期；不写日志；不申请新权限。
- 安全提示：明文 HTTP 风险、优先 SSH 本地转发、主机端保活。
- 地址归一化抽成纯函数 `RemoteHostUrl`，配 11 项 JUnit 测试（`RemoteHostUrlTest`），不依赖真机。
