## 本版改动

1. **引擎升级 rc.1 → rc.3**：改用上游 `v1.6.0-beta.19` 运行时（149,687,538 字节，SHA-256 `85a18c09…2101bb`），
   重新施加本项目的原生修复（真实 `flock`、`fs.link` 不覆盖发布、PTY 背压/EOF、WebView 垫片），派生出新运行包。
2. **首页状态岛退役**：引擎状态不再常驻聊天页顶部；胶囊、收起把手、贴边面板全部收起。
   **但保留一个 44dp 齿轮入口**（贴右上、跟随状态栏 insets）——因为齿轮原本是主界面进入设置页的唯一入口，整条隐藏会让人再也进不去设置。
3. **设置页显示实时引擎状态**：「设置 → 引擎」行副标题按 `EngineSupervisor` 状态显示
   「已就绪 · 端口 N / 启动中 / 安全模式 / 未运行」，点开仍是原来的状态对话框（可重启引擎）。
4. **新图标**：自适应图标前景替换为用户提供的鲸娘素材，背景改纯白（避免圆形遮罩裁出蓝边）；单色层保留供 Android 13 主题图标使用。
5. 多语言补齐（de / pt-BR / ru / th 新增 4 条引擎状态文案），`check-i18n.py` 仍为 exit 0。

## 关于「升级到 0.2.2-rc.5」

**没有做，原因是缺少可用产物，不是遗漏**：

- npm 上 `@deepseek-ai/dsh` 的 `next` 确实是 `0.2.2-rc.5`；
- 但**没有**对应的预构建 Android 运行时。最新上游运行时 `v1.6.0-beta.19` 的 `BUILD.json` 声明 `engineVersion: 0.2.2-rc.3`，
  我逐个核对了更早的 beta 版本，都不到 rc.5；
- 运行时里的 Node 是 ARM64 二进制，在 Windows 上无法执行，因此不能在这里 `npm install` 就地升级引擎。

所以本版如实标注内置 `0.2.2-rc.3`。要真正到 rc.5，需要**设备端升级**（App 内用自带包管理器把 `@deepseek-ai/dsh*` 升到 rc.5 并重新解析依赖），
那是一个新功能，不是换一个运行时文件能完成的。
