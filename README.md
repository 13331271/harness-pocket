# Harness Pocket 0.2.2 · Android 独立本地版

本仓库是 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）在 Android 上的**第三方非官方本地运行壳**：把官方 Agent 引擎连同 Android/Bionic Node 运行时一起装进手机，开机即用，不需要电脑、不需要服务器、不需要 Termux。

应用内运行的是真正的 DSH 引擎（本构建内置 `0.2.2-rc.3`），会话、工作区、凭证都留在应用私有目录；只有模型请求会发往你自己配置的 API 地址。模型推理不在手机上跑，也不预置任何 API Key。

> 与 DeepSeek 官方无隶属或背书关系。`DeepSeek`、`DeepSeek Harness` 等名称归其权利人所有。

成品 APK 与源码中不再出现原社区作者的账号与社群信息：

- 移除「关于」页的作者署名、个人仓库地址、QQ 群号、Telegram 群链接、Star 拉票卡片、致谢者名单与仓库引用列表。

- 本地识别应用、语音服务的第三方仓库入口改为不可用提示，不再跳转他人 Release 页。

**保留项**：MIT/Apache-2.0 等许可证要求的版权声明与 `NOTICE`（其中记录了派生的 MIT 代码与容器运行器的专有许可边界），以及插件市场里社区插件的仓库地址（这是市场功能本身的数据，不是本应用的身份信息）。关于页新增「开源许可」入口，直接展示随包内的 `LICENSE` 与 `NOTICE` 全文。

### 2. 新增「远程主机」

借鉴社区手机客户端的常见用法，本版加入**连接另一台机器上的 DSH**：

- 设置 → 连接 → **远程主机**，填写地址与可选 token，可先「测试连接」再打开。
- 适用于：局域网内已监听非回环地址的 DSH；通过 SSH 本地端口转发暴露出来的 `http://127.0.0.1:PORT`；反向代理后的地址。
- 该页面使用**独立 WebView**，不启动、不接管、不影响本地引擎；地址与 token 只存在应用私有偏好里，不会写到日志。
- 页面会提示明文 HTTP 的风险与后台保活注意事项。

- 完整 DSH Web UI：会话、工作区、插件、工具审批
- 本机原生引擎：Android/Bionic Node，无 proot、无 Linux 容器依赖

## 明确不包含

- **专有 Linux 容器运行器**及其全部 ABI 二进制、图形资源。该组件未获得定制再分发许可，因此本构建**不编译、不打包**，相关界面会说明不可用。
- 任何 API Key、账号、会话记录、签名私钥或本机 DSH 配置。
- 任何遥测、统计或追踪代码（本构建没有自建服务端）。

## 安装与首次使用

1. 把 APK 传到手机，用系统安装器侧载。它是个人本地签名包，不是官方签名发行版。
2. 首次启动选择语言与「普通模式」。内置运行时会解压到应用私有目录，建议预留 2GB 空间。
3. 在 WebUI 里配置你自己的模型服务地址、模型名与 API Key。
4. 先用无敏感数据的临时工作区测试对话与文件读写，再逐项开启手机能力。

**卸载会清除应用私有会话、工作区、配置与凭据。** 升级请保留同一签名直接覆盖安装，升级前先手动备份需要的数据。

## 构建

需要完整 JDK 21（必须含 `jlink`）、Gradle 8.9、Android SDK Platform 36 / build-tools 36.0.0、NDK `26.1.10909125`、CMake 3.22.1、Python 3。`targetSdk` 保持 28 以维持侧载原生二进制执行兼容性，这不是 Google Play 上架配置。

```powershell
$env:JAVA_HOME = '<完整 JDK 21>'
$env:ANDROID_HOME = '<Android SDK>'
$env:GRADLE_USER_HOME = '<独立 Gradle 缓存>'
gradle -p . -Pabi=arm64-v8a -Ppackage=full -PruntimeZip='<已核查的运行时 zip>' `
       -PupdateRepo=13331271/harness-pocket :app:testReleaseUnitTest :app:assembleRelease
```

运行时 zip 不是本仓库产物：它由固定的上游发布包加本项目的原生修复（真实 flock、`fs.link` 不覆盖发布、PTY 修复、WebView 垫片）派生而来，派生前后的 SHA-256 与修改清单见 `runtime-meta.json` 一类的元数据文件。**不要**直接重跑上游收集脚本当作修复后的运行包。
